# Sources et ressources historiques

- `hypercube/Hypercube.blend` : source actuelle du modèle d’introduction.
- `hypercube/archive/Hypercube.blend` : ancien fichier conservé depuis `Sources/`.
- `intro/video-Intro.mp4` : ancienne animation vidéo, conservée comme référence.
- `legacy/styles/` : anciens styles qui ne sont plus chargés par les pages.

Ces fichiers ne sont pas nécessaires à la lecture du site. Les sauvegardes
automatiques Blender (`.blend1`, `.blend2`, etc.) restent locales et sont
ignorées par Git. Voir [le guide d’export](../assets/models/README.md).
