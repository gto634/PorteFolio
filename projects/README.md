# Médias originaux des projets

Chaque projet conserve son dossier : `NecromancerMagicalGirl`, `Tatamiam`,
`IsekaiWar`, `Entrecote` et `SpaceRunner`.

- `Splashscreen.png` : fond du projet.
- `Thumbnail.png` : miniature de collection et affiche vidéo.
- `Gameplay.mp4` : vidéo originale lorsqu’elle est disponible.

Les variantes supplémentaires sont conservées à côté des originaux. Le site
charge les dérivés dans `assets/`, pas ces fichiers directement.
Après un remplacement, suivre [le guide des médias](../assets/README.md).
Le dossier du nouveau projet reste [NecromancerMagicalGirl/](NecromancerMagicalGirl/README.md).
